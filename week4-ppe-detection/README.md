# SiteGuard AI — PPE Detection Tool for a Regional Real Estate Agency
### Week 4 — Computer Vision Fine-Tuning (Specialist/Advanced)

## 1. What I Built and Why

This project fine-tunes a pre-trained YOLOv8 object detection model to identify
personal protective equipment (PPE) - specifically hard hats, safety vests,
and bare heads - in site/property images. The goal is to help a Regional Real
Estate Agency verify safety compliance during property inspections and
construction-site visits, where manual visual checks are currently slow and
inconsistent.

See SCOPE.md for the full scope statement written before development began.

## 2. Tools and Techniques Used

- Ultralytics YOLOv8 (yolov8n, nano variant - chosen for CPU-only training)
- Dataset: HardHat & SafetyVest Computer Vision Dataset (Roboflow Universe,
  PPE Kit Detection), 3 classes: head, helmet, vest
- Transfer learning: started from COCO-pretrained weights, fine-tuned on our
  PPE-specific data rather than training from scratch
- Data augmentation: hue/saturation jitter, horizontal flip, mosaic
  augmentation (combines 4 images per training sample)
- Scaling experiment: repeated fine-tuning at 3 training-data sizes (100, 300,
  600 images) with an identical, held-out validation/test set across all
  three, to measure how accuracy scales with data volume

## 3. What I Tested and What I Found

### Baseline (no fine-tuning)
mAP50 = 0.24% - effectively unusable, since the stock COCO-trained model has
never seen "helmet" or "vest" as a concept.

### Fine-tuned results by training-data size

| Training images | mAP50 (all classes) | mAP50 (head) | mAP50 (helmet) | mAP50 (vest) |
|---|---|---|---|---|
| 0 (baseline)     | 0.24%  | -      | -      | -      |
| 100              | 53.1%  | 48.4%  | 74.7%  | 36.1%  |
| 300              | 66.5%  | 66.6%  | 80.3%  | 52.6%  |
| 600              | 71.9%  | 67.2%  | 83.3%  | 65.2%  |

Accuracy increased consistently as training data grew (0.24% -> 53.1% -> 66.5%
-> 71.9%), confirming performance scales with dataset size in this range.
"Helmet" was the easiest class throughout (high-contrast, distinct dome
shape); "vest" was the hardest, though it improved the most with more data
(36.1% -> 65.2%), suggesting vest detection benefits most from additional
training examples.

A confusion matrix and per-class precision/recall are auto-generated by
YOLO for each run, saved at runs/detect/train_size_600/confusion_matrix.png
and runs/detect/train_size_600/results.csv.

### Failure case gallery
See failure_gallery/ folder - 12 validation images where the 600-image model
produced incorrect or missed detections, with notes on the likely cause
(lighting, partial occlusion, small/distant objects, class confusion between
head and helmet at odd angles).

## 4. Recommendation for the Regional Real Estate Agency

The fine-tuned model (600-image version, 71.9% mAP50) is accurate enough for
a supporting/advisory role - flagging likely non-compliant site photos for a
human reviewer - but is NOT yet reliable enough for fully automated
pass/fail decisions, since roughly 1 in 4 detections can still be wrong,
particularly for the "vest" class in poor lighting or partial-view photos.

Recommended image-capture rules to improve real-world accuracy:
- Capture photos in good, even lighting (avoid strong backlight)
- Keep the full person/torso in frame (avoid heavy cropping of the vest area)
- Capture from a front or three-quarter angle rather than directly from above/behind

## 5. Limitations and What I Would Improve

- Training was CPU-only, which limited us to small data subsets (max 600 of
  ~15,000 available images) and modest epoch counts (30); a GPU would allow
  training on the full dataset for a stronger final model
- The "vest" class underperforms "helmet" across all data sizes - more
  vest-specific training examples, or vest-focused augmentation, would help
- With more time: deploy the fine-tuned model behind a simple upload-and-detect
  web interface for non-technical agency staff, and tune confidence
  thresholds per class based on the failure gallery

## How to Run This Project

1. Download the dataset via download_dataset.py (requires a Roboflow API key)
2. Run make_subsets.py to create the 3 training-size subsets
3. Run baseline_test.py for the pre-trained baseline
4. Run train.py <size> for each size (100, 300, 600) to fine-tune
5. Results and weights are saved under runs/detect/<run_name>/
